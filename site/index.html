A SMALL INSTALL. A FAMILIAR WORKFLOW.

Ready when you are.

AVENC’s Python wheels include the native tools and their ecCodes libraries. Install FFmpeg separately, with the encoders you want to use.

Linux

sudo apt install ffmpeg
pip install avenc

macOS

brew install ffmpeg-full
export PATH="$(brew --prefix ffmpeg-full)/bin:$PATH"
pip install avenc

Python 3.11–3.14 · Linux x86_64 / ARM64 (glibc ≥ 2.28) · macOS Intel / Apple Silicon (15+) · FFmpeg ≥ 5.1. On Windows, use WSL.

Keep the scientific context.

Video-lossless preserves video codes. Quantization and precision conversion can still change scientific values. Choose a profile and validate it for your dataset.

Selective reads may decode preceding GOP frames and full spatial frames. Network transfer and speed depend on the file, server, selection and cache; a small requested array is not a promise of a small decode.

Zarr export is experimental (Zarr v2, per-stream layout). Inspect its metadata before using it in a downstream analysis.
